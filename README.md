## 厦港 IPLC 是什么

厦港 IPLC 是 Mkcloud（2023 年成立的跨境专线服务商）旗下“福建-香港高防 IPLC 专线”产品线的厦门方向，入口为厦门 BGP，出口为香港 BGP。它的兄弟产品是泉州电信入口的泉港专线，两者共同构成 Mkcloud 的高防 IPLC 方向。

它交付的形态是 VPS，而不是裸专线。每台机器分配 1 个独立入口 IP 和 1 个独立出口 IP，你连入口操作，业务程序在 VPS 里运行，流量自动从香港出口发出。这个结构决定了它的典型用法：跨境电商运营、对港金融业务、游戏和直播这类容易挨 DDoS 攻击的出海业务，都把香港出口当“出发点”，而不是把这台机器当公开网站服务器。

需要一开始就分清的是产品归属：Mkcloud 的产品线覆盖广港 IEPL、深港 IX、沪港/沪日/沪美 IPLC 与 IX、福建高防 IPLC（厦港/泉港）和上海 CN2。厦港属于其中定位最贵的一档——独享带宽、不限流量、自带高防，不是 158 元/月那种共享流量套餐的同类品。

## 高防到底防什么：官方自己泼的冷水

这是厦港 IPLC 测评里最容易被带偏的部分。官方产品页写的是“默认含 100Gbps 高防，防御可定制升级，可申请开通无视海外攻击与 UDP 攻击”，历史活动公告提到过 300Gbps 的容量数字。

但 Mkcloud 知识库在《高防专线怎么选》和《厦港、泉港专线选型说明》两篇文档里明确说了三件事：

1. 保护对象、阈值、清洗范围和触发条件**暂不公开**，有明确防护需求要通过工单咨询，而不是“仅凭旧文章中的 100G、300G 数字下单”；
2. 高防不等于业务不中断，应用层攻击、连接耗尽这类威胁需要单独评估；
3. 默认**无 SLA 保证**，需要可用性承诺得先谈定制协议。

换句话说，“防多大攻击”没有一个可以直接写进合同的数字，除非你购买前找客服确认。对于打算把金融交易或大促电商挂在上面的人，这一步建议在下单前做完，而不是出事后补。

## 延迟与使用边界：1~2ms 是什么意思

官方给的端内参考延迟是 1~2ms。这个数字指的是入口到出口的专线内部耗时，不等于你家里宽带连上入口、再从香港出口访问目标网站的全程延迟。厦门本地电信用户到入口的耗时另算，同城或同省也不保证始终最快，官方自己的建议是从实际宽带测。

比延迟更重要的是两个产品边界，很多导购文不会写：

- **出口不支持外部连入。** 这台机器不能当公开游戏服务端、买家访问的网站或支付回调入口。如果你的业务需要“别人主动连过来”，厦港 IPLC 满足不了这个需求。
- **直连产品绑定一个连入省份。** 入口只允许绑定省份的 IP 连接，绑定可以自行切换。福建用户问题不大，外省用户要确认自己的宽带能连厦门入口。

第三方测评方面，目前搜得到的独立实测文章主要集中在这家的广港和沪日产品上（比如 NodeSeek 上的广港 IEPL 实测，端内延迟 2.05ms 左右），厦港方向的独立长时间实测数据很少。所以对这条线，官方资料仍然是主要依据，这点和那些测评满天飞的热门产品不一样。

## 适合谁买，不适合谁

适合的情况其实很窄，但窄得清楚：

- 业务本体容易被 DDoS 盯上（游戏相关、金融交易、大促电商、直播），且需要持续稳定的独享带宽出港；
- 运营者或公司在福建（尤其厦门、泉州），本地宽带连 BGP 或电信入口质量好；
- 每月 6000 元起、先月付试水的预算完全可以承受，这类预算在跨境业务成本里通常只占小头。

不适合的情况同样明确：个人翻墙用途（违法且违反服务条款）、需要公开建站或接收回调的业务、想找便宜大流量香港 VPS 的人（这台机器不限流量但没有公开入口）、以及预算在一两千元以内还想上独享高防的用户——同类需求建议直接看共享线路或单独采购高防 IP，总价会低不少。

## 常见问题

**厦港 IPLC 的 1~2ms 是全程延迟吗？**
不是。这是专线端内的参考值，你的完整体验等于“本地宽带到厦门入口 + 端内 1~2ms + 香港出口到目标网站”三段之和。官方建议按《专线测速自测》的方法记录正常和高峰时段表现。

**厦港和泉港选哪个？**
配置和防护理事相同，泉港便宜 400~20000 元不等。核心差别在入口：厦门 BGP 对厦门及周边用户更近，泉州电信对泉州方向电信宽带用户更友好。用实际宽带分别测入口延迟再定。

**有没有优惠码？**
目前没有可核验的现行优惠码。历史上的 MK-8.8、MK-7.8、MK-NEW 等仅限活动期，官方知识库已标注失效。新活动关注官方 Telegram 通知群和 NodeSeek 商家帖。

**可以拿它做游戏服务器或建站吗？**
不可以对外开放。出口 IP 不接受外部连入，这是产品设计决定的。它可以运行的游戏、金融类业务是“从机器主动向外发起”的那种。

**支持退款吗？**
仅质量问题退款，需工单提交证据，商家审核。开通后不能换地域。所以建议首单月付，验证完延迟和稳定性再考虑长周期。
